---
Go to AccessBay > Activations to see the sites that use your licences. A site appears here when a customer enters a
licence key in the plugin. Until then the screen says "No sites have activated yet". Search, filters, saved views and
shareable links are described in [Search and filters](/guide/finding-things/).

## Columns

| Column | What it shows |
|---|---|
| Site | The site's address. A "Staging" tag marks a site AccessBay treats as a staging copy. |
| Licence | A link, "Open licence", to the licence the site uses. |
| Plugin version | The version of the plugin that last reported in. |
| Last seen | When the site last contacted AccessBay, or "Not yet". |
| Status | Live, or Deactivated. |
| Actions | The **Deactivate** button. |

Click **Last seen** or **Site** to sort by it.

## Filters

- **Status:** Live, Deactivated.
- **Staging:** Staging sites, Live sites.

## Deactivate a site

Select **Deactivate** in a row and confirm "Deactivate site". The site stops counting against the licence's site limit
at once. It can activate again with the key.
