Activate a licence on a site

POST
/licenses/activate

Activates a licence on a site, or re-activates it with a new token; answers the token once and the signed access object.

Request Bodyrequired

Section titled “Request Bodyrequired”
Media typeapplication/json

plugin_version

The version of the vendor plugin the client runs, stored on the activation. Optional; an older client sends none. A value that does not match ^[0-9]+(\.[0-9]+){0,3}(-[0-9A-Za-z][0-9A-Za-z.-]{0,20})?$ (at most 32 characters) is ignored, not refused.

string
environment
string
Allowed values: production staging development local
nonce
required

A random value the signed access object echoes; the client rejects an answer without it (SR-8).

string
/^[A-Za-z0-9_-]{16,128}$/
ttl

Seconds the client wants the deadline to reach; clamped to the access_deadline_cap_days setting.

integer
>= 1 <= 315360000

Section titled “429”

A rate limit is spent (accessbay_rate_limited): wait Retry-After seconds and retry. It says nothing about the credential or the data, so never read it as a refusal or as “nothing found”.

Section titled “503”

Temporarily unavailable (accessbay_temporarily_unavailable): a limit counter, storage or the database could not serve the request, a crypto refusal or a lost database connection outlived its retries, or (on a PUBLIC or API route) a health check holds unauthenticated routes off. Retry after Retry-After seconds; it never means the request or credential is invalid.
