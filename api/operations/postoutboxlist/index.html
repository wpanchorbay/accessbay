    • Operations
      • Deactivates the activation a token names, freeing its seat; false when it was already deactivated.
      • Records that a live activation was seen (at most hourly).
      • A page of activations across licences, newest first: site, plugin version, last seen and staging flag. Filter by live or deactivated and by staging.
      • The current user's AccessBay capabilities.
      • The mail drivers this site has: id, label, the fields each takes and what it can carry.
      • The health of every mail provider (ok, failing, paused or unknown), when it was last and will next be checked, the open incidents, and when the hourly check last ran. Computed on the server from sends, tests, checks and the circuit.
      • Every mail provider in priority order. A secret is never returned: has_secret says whether one is stored.
      • Adds a provider at the end of the chain. Each field is checked against the driver. Secrets are sealed and never returned. Audited.
      • Sets the chain order: every provider id, first to last, each once. Audited.
      • Deletes a provider. The last enabled provider is refused with 409. Audited.
      • Changes a provider. Only the fields sent change; a secret left out or empty keeps the stored one. `enabled` false is refused with 409 when it would leave none enabled. Audited.
      • Tests a provider's credentials; a driver with no check call sends a test email to the caller's address. A pass closes its circuit. Limited to ten per user per ten minutes. Audited.
      • Sends one short fixed test email to any address through this provider only (no fallback to the others), logs it in the mail log as a test and records the outcome. The address must be valid and not on the suppression list. Limited to ten per user per hour. Audited.
      • A page of the site-wide wp_mail log (recipients, subject and result, never a body), newest first, optionally of one result and a recipient search. A POST because it returns addresses.
      • A page of suppressed addresses, newest first. A POST because it returns addresses.
      • Lifts one suppression (idempotent: deleted is false when it was already gone). Audited.
      • A page of outbox emails, newest first, optionally of one status, delivery fact or provider.
      • Cancels a queued or held email that no worker holds. Any other status is refused (409). Audited with the reason.
      • One email: its fields, every attempt, every provider event, the pipeline status and delivery fact, and the resend chain. A POST because it returns the recipient. Unknown id: 404.
      • Sends an accepted, failed or suppressed email again as a new row (resend_of set, key resend:{id}:{n}), rendered again from current data. At most 5 per original per hour (429). A suppressed recipient is refused (409) unless lift_suppression is true, which lifts it first as its own audit entry. Audited with the reason.
      • Puts a failed, held or waiting email back in the queue now: same row and uuid, attempts kept, retry horizon reset. Any other status, or a row a worker holds, is refused (409). Audited.
      • Counts for the admin home: licences, live sites, licences expiring within 30 days and revocations in the last 30 days.
      • Searches licences (by uuid, last four characters or a pasted key), customers, orders and products. Terms under two characters find nothing. The pasted key is never stored, logged or returned.
      • Every settings section with its schema and current values; a secret setting answers only whether it is set.
      • Erases all of the site's AccessBay data (tables, options, products, keys, storage) and sets the plugin up again, still active; site administrators only (super admins on multisite), with confirm ERASE and the user's password.
      • Changes settings of one section, all or nothing; a refused value answers 400 accessbay_setting_invalid with each refused key in data.fields.
      • Creates an API key. The response is the only place its secret ever appears: show it once. Each scope needs the capability of its admin counterpart: licenses:read manage_accessbay_orders, licenses:write manage_accessbay_orders and refund_accessbay_orders, licenses:reveal reveal_accessbay_keys (403 accessbay_api_key_scope_forbidden). Audited.
      • A page of API keys, newest first: never the secret. Pass the previous page's next_before_id as before_id.
      • Revokes an API key for good: it stops authenticating at once. Revoking a revoked key returns it unchanged. Audited.
      • A page of customers (search by uuid, email, last name or company start; sort; page).
      • A customer with their licences (key_last4 only) and newest orders. Read-only.
      • Every health check with its latest result, and the stored alerts.
      • A random body sent with no-store; two equal answers mean a cache ignores origin headers (RC-16).
      • Health ping for a monitor that can only GET; a cache that ignores no-store can answer it (prefer POST).
      • Health ping for an external monitor (use POST): 200 or 503, the status and the age of the newest result.
      • Confirms that the local storage folder is not web-reachable, for a host where AccessBay can neither prove it from the filesystem nor probe it. Send the fingerprint RC-2 reported; a moved folder or host voids the confirmation and asks again. Refused (409 accessbay_storage_attestation_unavailable) when RC-2 is not currently unverified, the fingerprint is not the current one, or the folder was found web-served. Audited.
      • Activates a licence on a site, or re-activates it with a new token; answers the token once and the signed access object.
      • Bundle resolution: which of the listed products a key covers, with the signed access object (no activation).
      • A page of licences, newest first; key_last4 only.
      • Validates a key for a product on a site it is activated on; answers the licence state and the signed access object. Mutating only in that it records the plugin version the client reports when that differs from the stored one; a repeat of the same version writes nothing.
      • A page of one licence's activations, newest first.
      • Ends one site's activation of a licence as an admin: the seat is free at once. Audited. A repeat changes nothing and answers deactivated false.
      • A licence with its activations, contributions, access window and newest timeline rows; key_last4 only.
      • A page of a licence's timeline, newest first.
      • Adds days to a licence as a grant contribution, after the end of its access or from now. A lifetime or subscription licence and a revoked one are refused (409); the same request_key again with the same days and reason returns the first grant with created false, and with other days or another reason is refused (409, request_key_reused). The reason is operational text and must not hold customer personal data. Audited.
      • Appends an admin note to a licence's timeline.
      • Replaces the licence key with a new one; the old key stops matching, activations stay. Audited; the response carries key_last4 only.
      • Returns a licence's key once, rate-limited per user and audited.
      • Revokes a licence for good: no reinstate. Audited.
      • Sets the seat limit (null is unlimited). Lowering it below the live count keeps those activations and refuses new ones. Raising it or setting it to unlimited needs the refund capability (403 without it). Audited.
      • Suspends a licence (the admin hold): access stops until it is unsuspended. Audited.
      • Activates a test-mode licence on a site, as the public route would. Answers only while the site is in test mode (409 otherwise); a live licence is not found. Never returns the key or the activation token.
      • Checks whether a test-mode licence is activated on a site and valid. Answers only while the site is in test mode (409 otherwise); a live licence is not found.
      • Clears the admin hold; a dispute hold stays, and access is recomputed from the facts. Audited.
      • Receives a mail provider's delivery events. The provider's own signature decides; the uuid only routes.
      • The signed, public metadata document of a published release: latest.json (the newest live stable release), latest-beta.json (the newest beta or stable one, on an install that offers beta; stable otherwise) or {version}.json.
      • A page of orders (filter by source, payment status and fulfilment status; search by number or uuid).
      • Ends access on a paid WooCommerce order (a goodwill refund keeps it): reverses every unit still held, with an audit row.
      • An order with its lines, payments, fulfilment_error and the licences issued (key_last4 only). Read-only.
      • Records a dispute on the order and suspends its access until it is closed.
      • Closes the order's dispute: won restores access, lost reverses it and moves the order to charged_back.
      • A single-use URL, valid for 60 seconds, for the newest stable package (or, with channel=beta on an install that offers it, the newest beta or stable one) of the product the activation token in X-AccessBay-Activation is licensed for.
      • Redeems a single-use package ticket once, sent as the `token` form field so it never appears in a URL: the ZIP, or a redirect to a signed storage URL that lives at most 60 seconds. Same answers as getPackage.
      • Redeems a single-use package URL once: the ZIP, or a redirect to a signed storage URL that lives at most 60 seconds.
      • The portal page's first call: authenticates by AccessBay's portal session cookie (not WordPress's login) and returns what the session opens and its CSRF token. Same-origin only.
      • Mails the claim link to the address stored on the portal session's guest row. Authenticated by the portal session cookie and its CSRF header; same-origin only. The same body whether a mail was queued or not.
      • Redeems an account-claim token, once, for the logged-in WordPress account (cookie session with the REST nonce): links the guest row to it, or merges the row's orders and licences into the account's own row. Same-origin only; the link's page sends this after the visitor confirms.
      • Asks for a sign-in link to be mailed to the address on file. Always answers the same body, whether the address is known, unknown or the caller limited; the mail goes only to the stored address. The limits that apply are not announced: this route holds outer floors only.
      • Redeems a key-recovery token, once, and starts the portal session (the cookie and the answer are those of `/portal/redeem`). Same-origin only; the link's page sends this after the visitor confirms.
      • The signed-in customer's licences (an order-access session: only that order's), key_last4 only. Needs the portal session cookie and the X-AccessBay-Portal-CSRF header; same-origin only.
      • One licence of the session with its sites; key_last4 only. Needs the portal session cookie and the X-AccessBay-Portal-CSRF header; same-origin only.
      • Ends one site's activation of the session's licence, freeing its seat at once. A repeat changes nothing. Audited. Needs the portal session cookie and the X-AccessBay-Portal-CSRF header; same-origin only.
      • Issues a single-use download URL, valid 60 seconds, for the licence's newest or previous version; redeem it with GET /packages/{token}. Needs the portal session cookie and the X-AccessBay-Portal-CSRF header; same-origin only.
      • Returns the licence key once to its signed-in customer: rate-limited per customer and audited. Needs the portal session cookie and the X-AccessBay-Portal-CSRF header; same-origin only.
      • Redeems a magic-link or order-access token, once, and starts the portal session: sets the session cookie (HttpOnly, SameSite=Lax) and replaces any session the browser held. Same-origin only; the link's GET page sends this.
      • Ends the portal session: deletes its row and expires the session cookie. Needs the portal session cookie and the X-AccessBay-Portal-CSRF header; same-origin only.
      • One page of the active prices a WooCommerce product can be mapped to, newest first, each with its product. Pass next_before_id back as before_id for the next page; null means the last page.
      • Archives a price: no longer offered; orders that reference it keep it.
      • How many orders and licences already use the price, and its recorded changes (old terms, new terms, who, when), newest first.
      • Changes the terms of a price. A price orders or licences already use is refused (accessbay_price_referenced) unless the request sends confirm_referenced: true; orders and licences keep the terms they were sold with and only new sales get the new terms. Each change is recorded.
      • Live activations of a product per reported plugin version, most sites first (AccessBay Pro).
      • Creates a draft product and its page. A software product also gets its licence entitlement, keyed by its slug: the `product` its licences are activated with. Its slug is at most 64 characters (accessbay_slug_not_a_licence_key), and a slug that is already a key is refused (accessbay_duplicate_slug).
      • One page of products, newest first, each with its number of prices. Pass next_before_id back as before_id for the next page; null means the last page.
      • Activates a draft product so it can be sold; an active product stays active. An archived product is refused (accessbay_product_archived). A product with no active price is activated and still can not be bought until a price exists. A software product with no licence entitlement is refused (accessbay_product_no_entitlement).
      • Archives a product: no longer sold; its prices and licences stay.
      • A product with all its prices, archived ones included. {id} is the product's uuid or its integer product_id.
      • Adds a price to a product.
      • Uploads a release ZIP (multipart, field `package`) as an unpublished draft; the version comes from the ZIP.
      • A product's releases, newest first, drafts and yanked ones included, and the channels this install offers. {id} is the product's uuid or its integer product_id.
      • Changes a product's name or slug. A software product's licence entitlement keeps the slug it was created with, so licences already sold and the clients using them keep working.
      • Signs and publishes a draft release; a published release is immutable.
      • Withdraws a published release from updates and downloads.
      • Maps a WooCommerce product, or one of its variations, to an active AccessBay price in the current mode. A downloadable product is refused, and so is a product already mapped.
      • One page of WooCommerce products with their variations and the AccessBay price each sells in the current mode.
      • Moves a WooCommerce product or variation from the price it sells (which may be archived) to another active price in the current mode. Orders already mirrored keep their price.
      • Removes the price a WooCommerce product or variation sells in the current mode, if it still sells the price named. Orders already mirrored keep their price.
      • The thank-you page island's poll: takes WooCommerce's order id and order key and answers the fulfilment state; once fulfilled it also returns an order-scoped token for the portal (no licence keys here). Same-origin only.

503

Section titled “503”

Temporarily unavailable (accessbay_temporarily_unavailable): a limit counter, storage or the database could not serve the request, a crypto refusal or a lost database connection outlived its retries, or (on a PUBLIC or API route) a health check holds unauthenticated routes off. Retry after Retry-After seconds; it never means the request or credential is invalid.
