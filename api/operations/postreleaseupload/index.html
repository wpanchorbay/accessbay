Upload a release

POST
/products/{id}/releases

Uploads a release ZIP (multipart, field package) as an unpublished draft; the version comes from the ZIP.

503

Section titled “503”

Temporarily unavailable (accessbay_temporarily_unavailable): a limit counter, storage or the database could not serve the request, a crypto refusal or a lost database connection outlived its retries, or (on a PUBLIC or API route) a health check holds unauthenticated routes off. Retry after Retry-After seconds; it never means the request or credential is invalid.
